
Название
Сортировка списка фильмов и сериалов по рейтингу зрителей и кинокритиков.
Цель
Дать пользователям возможность сортировать список фильмов и сериалов в разделе «Библиотека» по рейтингу зрителей и/или рейтингу кинокритиков 
Требование
Пользователь должен иметь возможность выбрать в интерфейсе параметр сортировки (rating или criticsRating) и направление сортировки (asc / desc), после чего получить отсортированный список контента 
UseCase
В разделе «Библиотека» пользователь видит список фильмов и сериалов.
Пользователь в интерфейсе выбирает параметры, по которым он хочет отфильтровать список фильмов и сериалов, и/или режим сортировки.
Система возвращает список фильмов и сериалов, отфильтрованный и отсортированный согласно указанным данным. При сортировке по рейтингу кинокритиков контент без оценки (criticsRating=null) отображается в конце списка, чтобы обеспечить приоритет контента с валидными оценками.
Описание изменений
Необходимо доработать Films Server API.
1.1. В ответ {{FilmsServer}}/​​films/list добавить новое поле criticsRating.
1.2. В ответ {{FilmsServer}}/​​films добавить новое поле criticsRating.
Необходимо доработать Series Server API.
             2.1.  В ответ {{SeriesServer}}/series/list добавить новое поле criticsRating. 
             2.2. В ответ {{SeriesServer}}/series добавить новое поле criticsRating.
Необходимо доработать Web Server API.
            3.1. В запрос GET /content/list добавить query-параметры sortBy и direction, реализовать сортировку объединенного списка с учетом правила размещения элементов с null в конце. 
           3.2. В ответ {{WebServer}}/content/list добавить новое поле criticsRating.
Контекст
В ответе запроса {{FilmsServer}}/films/list и {{SeriesServer}}/series/list уже есть рейтинг зрителей rating, по которому так же нужно будет выполнять сортировку.

Операции Web Server API

3.1. В запрос GET /content/list  добавить два query-параметра: sortBy и direction. 
Поле sortBy может принимать два значения:
Если “sortBy”: “rating”, внутри массива сортировка элементов должна выполняться по полю rating (рейтинг зрителей); 
Если “sortBy”: “criticsRating”,  внутри массива сортировка элементов должна выполняться по полю criticsRating (рейтинг кинокритиков). 
Поле direction может принимать два значения:
Если “direction”: “desc”, внутри массива элементы должны сортироваться по параметру sortBy по убыванию;
Если “direction”: “asc”, внутри массива элементы должны сортироваться по параметру sortBy по возрастанию.
Особые правила сортировки:
При sortBy=criticsRating элементы с criticsRating = null (или без этого поля) всегда отображаются в конце списка, независимо от значения direction (asc или desc).
Сначала сортируются только элементы с заполненным criticsRating; затем в конец добавляются все элементы с criticsRating = null в исходном порядке (стабильная сортировка).
При sortBy=rating аналогичное правило применяется к элементам с rating = null (или без этого поля): такие элементы всегда размещаются в конце списка.


Тип метода
GET
URL запроса
/content/list
Параметры запроса, которые нужно добавить
sortBy 
string 
Опционально 
Параметр сортировки. Допустимые значения: rating — сортировка по рейтингу зрителей; criticsRating — сортировка по рейтингу кинокритиков. Если параметр не передан, сортировка не применяется 

direction 
string 
Опционально 
Направление сортировки. Допустимые значения: asc — по возрастанию; desc — по убыванию. Используется совместно с sortBy. Если sortBy не передан, параметр игнорируется. Не влияет на порядок элементов с null — они всегда в конце списка 
Пример запроса
https://2ee4902e-6893-4bf2-9b6f-88b9f5fcb78a.mock.pstmn.io/content/list?sortBy=rating&amp;direction=desc
